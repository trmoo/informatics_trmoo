1. 이 앱이 무엇인가요

종이 학습지의 괄호 정답을 눈으로 읽고 끝내는 대신, 값을 바꾸고 실행해서 결과를 확인하게 만든 실습 앱입니다. 학습지 ①~㉒ 중 Ⅰ 컴퓨팅 시스템 · Ⅱ 데이터 · Ⅲ 알고리즘 · Ⅳ 파이썬 네 단원, 화면 16개가 들어 있습니다.

🔌 설치가 없습니다

파일 하나면 끝

  • 웹 브라우저만 있으면 됩니다
  • 파이썬을 깔지 않아도 파이썬 코드가 실제로 실행됩니다
  • 교실 인터넷이 끊겨도 그대로 작동합니다

✋ 직접 만져 봅니다

보여 주는 것이 아니라 해 보는 것

  • 허브와 스위치의 차이를 눈으로 봅니다
  • 허프만 트리를 직접 조립합니다
  • 정렬 알고리즘을 한 단계씩 재생합니다

✅ 채점이 됩니다

교사가 일일이 봐 주지 않아도

  • 괄호 정답은 가려 두고 [보기] 로 엽니다
  • 문제는 힌트·해설과 함께 자동 채점
  • 빈칸 코드는 실행 결과까지 채점
학생에게 나눠 줄 때 필요한 것은 index.html 파일 하나뿐입니다. 크기는 약 290KB 로, 이 안에 화면·그림·문제·파이썬 해석기가 전부 들어 있습니다.

3. 방법 ① 파일 하나로 쓰기 가장 쉬움

가장 빠르고, 인터넷이 끊겨도 되고, 학교 방화벽에 막히지 않습니다.

  1. 받은 폴더에서 dist 폴더를 엽니다 그 안의 index.html 과 설치안내.html(이 문서) 두 파일이 전부입니다.
    dist 폴더가 없다면 아직 빌드하지 않은 것입니다. 방법 ③ 의 npm run build 를 한 번만 실행하면 만들어집니다. 빌드된 파일을 받으셨다면 이 단계는 건너뛰세요.
  2. index.html 을 더블클릭합니다 기본 브라우저에서 바로 열립니다. 이것으로 끝입니다.
  3. 학생들에게 나눠 줍니다 아래 중 편한 방법을 쓰세요.
    방법하는 법
    USBindex.html 을 복사해 각 컴퓨터 바탕화면에 붙여 넣기
    공유 폴더컴퓨터실 공유 폴더(예: \\서버\수업자료\정보)에 올려 두고 바로 가기 만들기
    구글 클래스룸자료로 첨부 → 학생이 내려받아 더블클릭 (브라우저에서 미리보기로는 실행되지 않으니 내려받아 열도록 안내)
    학교 홈페이지자료실에 올리기. 첨부파일로 내려받아 열면 됩니다
왜 파일 하나로 끝날까요? 빌드할 때 화면·그림·문제·파이썬 해석기를 전부 index.html 안에 넣어 두었습니다. 그래서 인터넷이 끊긴 컴퓨터실에서도, 심지어 랜선을 뽑아도 똑같이 작동합니다.

5. 방법 ③ 코드를 고쳐 쓰기

문제 수치, 예제 데이터, 화면 문구를 내 수업에 맞게 바꾸고 싶을 때입니다.

  1. Node.js 를 설치합니다 nodejs.org 에서 LTS 버전을 내려받아 설치합니다. (한 번만)
  2. 앱 폴더에서 준비 명령을 실행합니다 
    cd D:\project_AI\22informatics_trmoo
npm install
    인터넷이 필요한 단계는 여기 한 번뿐입니다.
  3. 개발 서버를 켜고 고칩니다 
    npm start
    화면에 나오는 http://localhost:5173 을 브라우저에서 엽니다. src/ 안의 파일을 고쳐 저장하면 화면이 즉시 바뀝니다.
  4. 다 고쳤으면 다시 한 파일로 묶습니다 
    npm run build
    dist/index.html 이 새로 만들어집니다. 이 파일을 나눠 주면 됩니다.

7. 수업에서 쓰는 법

① 정답을 한꺼번에 열고 닫기

학습지의 ( 괄호 정답 ) 은 처음에 가려져 있고, 학생이 [보기] 를 눌러야 열립니다. 설명하실 때는 화면 오른쪽 위 [👁️ 정답 모두 보기] 를 누르면 그 화면의 모든 정답이 한 번에 열리고, 다시 누르면 닫힙니다. 탭을 옮겨도 이 설정이 이어집니다.

수업 흐름 제안 — ① 정답을 닫아 둔 채로 학생이 먼저 조작해 본다 → ② 짝과 이야기해 본다 → ③ 교사가 [정답 모두 보기] 로 한 화면을 통째로 열어 정리한다.

② 특정 화면 링크를 학생에게 주기

주소 끝에 #단원/화면 이 붙습니다. 이 주소를 그대로 복사해 주면 학생이 그 화면부터 열게 됩니다. 새로고침해도 보던 곳이 유지됩니다. (전체 목록은 아래 8번에 있습니다.) 

예) 진수 변환 화면만 바로 열기
https://trmoo.github.io/informatics_trmoo/#data/radix

③ 문제를 반마다 다르게 내기

IP 실험실, 저장 용량, 진법 변환 화면에는 [새 문제 만들기] 단추가 있습니다. 누를 때마다 숫자가 새로 만들어지므로 1반과 2반에 다른 문제를 낼 수 있고, 같은 학생이 여러 번 연습할 수도 있습니다.

④ 파이썬 실습실에서 input() 쓰기

브라우저에는 키보드 입력을 기다리는 검은 창이 없습니다. 그래서 코드에 input() 이 있으면 아래에 「⌨️ 미리 넣어 둘 입력값」 칸이 나타납니다. 여기에 한 줄에 하나씩 적어 두면 input() 이 위에서부터 차례로 읽어 갑니다.

학생들이 자주 막히는 곳 — 입력값을 적지 않고 실행하면 「입력할 값이 준비되어 있지 않습니다」 라는 오류가 납니다. 오류 문구 아래에 무엇을 해야 하는지 적혀 있으니 오류 문구를 읽는 연습의 기회로 쓰시면 좋습니다.

⑤ 무한루프가 걱정될 때

while 문을 잘못 써도 브라우저가 멈추지 않습니다. 출력이 3,000줄을 넘거나 실행이 너무 길어지면 앱이 스스로 멈추고 이유를 알려 줍니다. 학습지 ㉑ 의 「코드 ②」(무한루프 예제)를 안심하고 실행시켜 보세요.

⑥ 전자칠판·TV 로 띄울 때

글자와 버튼은 뒷자리에서도 보이도록 크게 잡아 두었습니다. 더 크게 하시려면 브라우저에서 Ctrl + + 를 누르세요. 레이아웃이 자동으로 다시 배치됩니다.

9. 자주 묻는 문제

더블클릭했는데 흰 화면만 나옵니다

① 인터넷 익스플로러로 열린 것이 아닌지 확인하세요. 파일을 오른쪽 클릭 → 연결 프로그램 → Chrome / Edge 로 여시면 됩니다.
② dist/index.html 이 아니라 프로젝트 맨 위의 index.html 을 연 것일 수도 있습니다. 그 파일은 개발 서버용이라 그냥 열면 빈 화면이 나옵니다. 반드시 dist 폴더 안의 파일을 여세요.

글자가 네모(□□□)로 깨져 보입니다

한글 글꼴이 없는 컴퓨터입니다. 맑은 고딕만 있으면 정상입니다. 브라우저 설정에서 기본 글꼴을 맑은 고딕 으로 바꿔 주세요. 이모지(🌡️ 💡 등)가 네모로 보이는 것은 윈도우 버전이 낮아서인데, 기능에는 문제가 없습니다.

파이썬 코드가 실행되지 않습니다 / 오류가 납니다

이 앱의 파이썬은 수업에 필요한 문법만 담은 교실용 미니 파이썬입니다. 학습지에 나오는 문법(변수·자료형·연산자·입출력·if·while·for·리스트·함수·클래스)은 진짜 파이썬과 똑같이 동작하지만, 파일 입출력, pandas·numpy 같은 외부 라이브러리, turtle, tkinter 는 지원하지 않습니다. 「자유 실습실」 맨 아래에 쓸 수 있는 문법 전체 목록이 있습니다. 수행평가 과제는 IDLE 이나 실제 파이썬으로 하도록 안내해 주세요.

그림(캔버스)이 비어 있게 나옵니다

다른 탭을 보다가 돌아왔을 때 잠깐 그럴 수 있습니다. 브라우저를 새로고침(F5)하면 다시 그려집니다. 화면 크기를 바꿔도 자동으로 다시 그려집니다.

학생이 푼 내용이 저장되나요?

저장되지 않습니다. 새로고침하거나 창을 닫으면 모두 사라집니다. 학생 개인정보를 저장하지 않기 위해 일부러 그렇게 만들었습니다. 제출이 필요한 활동은 학습지에 옮겨 적게 하거나 화면을 캡처해 제출하도록 해 주세요.

스마트폰이나 태블릿에서도 되나요?

됩니다. 화면이 좁으면 두 칸 배치가 한 칸으로 자동으로 바뀝니다. 다만 네트워크 조립대처럼 드래그가 많은 화면과 파이썬 코드 편집은 화면이 큰 기기에서 훨씬 편합니다.

npm install 에서 오류가 납니다

① Node.js 가 설치되어 있는지 확인하세요 (node -v 를 쳐서 버전이 나오면 정상).
② 학교 방화벽이 registry.npmjs.org 를 막고 있을 수 있습니다. 개인 네트워크에서 한 번만 받아 두면 node_modules 폴더째 옮겨 쓸 수 있습니다.
③ 반드시 앱 폴더 안에서 실행하세요. 상위 폴더(D:\project_AI)에서 실행하면 안 됩니다.

다른 프로그램이 그 포트를 쓰고 있습니다. 다른 번호로 켜면 됩니다.
