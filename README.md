# 정보 노트 실습실

고등학교 1학년 **「정보」** 학습지 ①~㉒ 를 브라우저에서 **직접 해 보는** 웹앱입니다.
값을 바꾸고, 눌러 보고, 코드를 실행해 보면서 배웁니다.

> 설치도 인터넷도 필요 없습니다. **파이썬도 이 안에서 실제로 실행됩니다.**

**🔗 바로 열기 → https://trmoo.github.io/informatics_trmoo/**

---

## 학생용 — 3줄 사용법

1. `dist/index.html` 파일을 **더블클릭**하면 열립니다. (또는 선생님이 알려 주신 주소로 접속)
2. 위쪽 큰 탭에서 **단원**을, 그 아래 알약 단추에서 **학습지 번호**를 고릅니다.
3. 학습지의 `( 정답 )` 은 가려져 있습니다. **먼저 스스로 생각한 뒤 [보기]** 를 누르세요.

## 📖 선생님이라면 여기부터

**[교사용 설치 안내 페이지 — `public/설치안내.html`](public/설치안내.html)** 를 더블클릭해 보세요.
설치 방법 3가지, 컴퓨터실 배포, 수업 활용법, 화면별 바로 가기 주소, 자주 묻는 문제까지
한 장에 정리해 두었습니다. **인쇄해서 나눠 주실 수 있습니다.**

> 빌드하면 이 안내문도 `dist/설치안내.html` 로 함께 복사되므로,
> `dist` 폴더째 나눠 주시면 앱과 안내문이 서로 링크로 이어집니다.
> 앱 화면 오른쪽 위 **[📖 교사용 안내]** 단추로도 열립니다.

## 무엇을 해 볼 수 있나요

### Ⅰ. 컴퓨팅 시스템
- **네트워크 조립대** — 허브·스위치·라우터·무선 AP를 놓고 케이블로 이은 다음 데이터를 실제로 보내 봅니다.
  허브를 쓰면 상관없는 컴퓨터까지 데이터가 날아가고, 스위치를 쓰면 목적지로만 갑니다. 눈으로 보세요.
- **사물 인터넷 조립기** — 센서 값을 바꾸면 내가 만든 규칙이 판정하고 전등·경보음·알림이 실제로 켜집니다.
- **IP 실험실** — 슬라이더를 밀면 32개 비트가 네트워크와 호스트로 갈라집니다.
  서브넷 마스크, 네트워크 주소, 브로드캐스트 주소, 쓸 수 있는 IP 개수가 그 자리에서 계산됩니다.

### Ⅱ. 데이터
- **진법 변환기** — 2·8·10·16진수가 한꺼번에 바뀌고, 왜 그 값인지 전개식과 나눗셈 과정이 나옵니다.
- **부호화 실험실** — 글자를 치면 아스키 비트열이 나오고, 픽셀을 직접 칠하면 파일 크기가 계산되고,
  소리의 표본화·양자화 슬라이더를 밀면 원래 소리와 얼마나 달라지는지 빨간 선으로 보입니다.
- **압축 실험실** — 런렝스는 압축했는데 **오히려 커지는 경우**까지 보여 줍니다.
  허프만은 트리를 조립하고 코드를 뽑아 압축률을 계산하고, 비트열을 다시 글자로 되돌려 봅니다.
- **암호 실험실** — 시저 암호, 전치형 암호, 그리고 **되돌릴 수 없는 단방향 암호**를 직접 돌려 봅니다.
- **빅데이터** — 값을 넣으면 선 그래프가 그려지고 최고점과 상관관계를 알려 줍니다.

### Ⅲ. 알고리즘
- **스택과 큐** — 직접 넣고 빼면서 후입선출과 선입선출을 몸으로 익힙니다.
- **분할정복 놀이공원** — 지도에서 장소를 눌러 길을 만들면 시간이 합산됩니다. 최단 경로를 찾아보세요.
- **정렬 경주** — 버블·선택·병합 정렬을 한 단계씩 재생하며 비교 횟수와 교환 횟수를 셉니다.
- **탐색 비교** — 순차 탐색과 이진 탐색이 위아래로 나란히 돌아갑니다.
  이진 탐색이 버린 범위가 흐려지는 것을 보세요.

### Ⅳ. 파이썬 — 진짜로 실행됩니다
- 파이썬을 설치하지 않아도, 인터넷이 끊겨도 **코드가 그 자리에서 실행**됩니다. 한글 변수명도 됩니다.
- 학습지 예제를 **결과를 먼저 예상해 적고 → 실행해서 비교**하는 방식으로 풀 수 있습니다.
- **빈칸 채우기** 과제는 빈칸의 답과 실행 결과를 함께 채점해 줍니다.
- **연산자 우선순위 계산기** — 수식을 넣으면 무엇을 왜 먼저 계산하는지 한 단계씩 보여 줍니다.
- **조건 갈림길 확인기** — 값을 바꾸면 실제로 실행되는 줄이 초록으로, 건너뛰는 줄이 빨강으로 표시됩니다.
- **도전 과제 8개** — 스스로 완성하면 자동으로 채점됩니다.

## 선생님용

- 화면 오른쪽 위 **[👁️ 정답 모두 보기]** 를 누르면 그 화면의 모든 괄호 정답이 한꺼번에 열립니다.
  설명이 끝나면 다시 눌러 닫을 수 있습니다.
- 주소창에 `#data/radix` 처럼 남으므로, 특정 화면 링크를 학생에게 바로 줄 수 있습니다.
- 문제 자동 생성 단추(IP, 저장 용량, 진법)는 누를 때마다 숫자가 바뀌므로 반마다 다른 문제를 낼 수 있습니다.
- 글자와 버튼은 교실 TV·전자칠판에서 보이도록 크게 잡았습니다.
- **학생 개인정보를 저장하지 않습니다.** 서버가 없고, 브라우저에도 아무것도 남기지 않습니다.
  창을 닫으면 푼 내용은 모두 사라집니다.

## 개발자용

```bash
npm install     # 의존성 설치
npm start       # 개발 서버
npm run build   # dist/index.html 한 파일로 빌드
```

- Vite + 바닐라 JavaScript, 외부 CDN 없음
- 빌드 결과는 `dist/index.html` **한 파일**(약 290KB)이라 USB에 담아 더블클릭으로 쓸 수 있습니다
  (교사용 안내문 `dist/설치안내.html` 이 함께 복사됩니다)
- 파이썬 해석기(`src/lib/pymini.js`)는 수업에 필요한 문법만 담은 **교실용 미니 파이썬**입니다.
  파일 입출력이나 외부 라이브러리는 지원하지 않습니다 — 수행평가 과제는 IDLE 에서 작성하세요.

자세한 개발 기록은 [CLAUDE.md](CLAUDE.md) 를 보세요.
